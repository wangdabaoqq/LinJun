# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-01-26

### Added

- Auto-update feature with update check functionality
- New application icon design

### Changed

- Updated app icon in Sidebar and QuotaWindowBar components
- Regenerated icon assets for all platforms (icns, ico, png)

## [1.0.0] - 2026-01-20

### Added

- Initial release
- Multi-provider support: Claude, Gemini, OpenAI Codex, Qwen, Antigravity, iFlow, Vertex AI
- Real-time quota tracking per account
- One-click agent configuration for Claude Code, OpenCode, Gemini CLI
- Live dashboard for monitoring request traffic and token usage
- Smart routing with Round Robin and Fill First strategies
- API key management for local proxy
- System tray integration
- Multilingual support (English and Simplified Chinese)
